rclone Drive Access

A personal utility for syncing my own Google Drive files to my own computer.

What this is

This page exists to support the OAuth consent screen for a personal Google Cloud project. The project provides an OAuth client ID used by rclone, an open-source command-line file-synchronisation tool, to read files from my own Google Drive accounts.

It is not a product, a service, or an application offered to anyone else. It has exactly one user: me, the account owner.

What it does

  • Reads documents and files from Google Drive accounts that I own.
  • Copies them to local storage on my own computer.
  • Converts documents into plain-text and Markdown files for a personal notes archive.

The OAuth client is configured with read-only Drive scope, so it cannot modify or delete anything in Drive.

Who can use it

Nobody else. There is no sign-up, no hosted service, and no shared deployment. The credentials live in a local rclone configuration file on a single machine.

Privacy

No data is collected, transmitted to third parties, sold, or shared. See the privacy policy for details.
