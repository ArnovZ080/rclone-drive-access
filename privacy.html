Privacy Policy

rclone Drive Access · Last updated 8 October 2026

This OAuth client is a personal utility with a single user: the account owner. It is not offered to the public and has no other users. See the overview for what it does.

What data is accessed

When authorised, the client uses the Google Drive API to read file names, folder structure, file metadata, and file contents from Google Drive accounts belonging to the account owner. It requests read-only Drive access and therefore cannot create, modify, or delete anything in Drive.

It does not access any other Google service, and it accesses no other person's account.

How that data is used

Files are copied to local storage on the owner's own computer and converted into plain-text and Markdown files for a personal notes archive. That is the only purpose.

How data is stored

  • Downloaded files and converted notes are stored locally on the owner's computer.
  • The OAuth access and refresh tokens are stored in a local rclone configuration file on that computer. They are not transmitted anywhere except to Google's own authentication endpoints.
  • There is no server, no database, and no hosted component of any kind.

Data sharing

No data is shared, sold, rented, published, or transferred to any third party. No analytics, tracking, advertising, or telemetry is used. No data is sent to the operator of this web page, because this page is static and collects nothing.

Google Drive data is never used to train machine-learning or AI models, and is never transferred to anyone for that purpose.

Retention and deletion

Local copies are retained for as long as the owner finds them useful and can be deleted at any time by deleting the local files. Authorisation can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions, which immediately ends the client's access.

Children

The client is not directed at children and has no users other than the account owner.

Changes

If this policy changes, the revised version will be published on this page with an updated date.

Contact

Questions about this policy can be sent to the email address listed as the developer contact on the OAuth consent screen for this project.
